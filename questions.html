Stacks & Queues — Applied Quiz

Ten questions testing whether you can apply FIFO (queues), FILO/LIFO (stacks), the push/pop/enqueue/dequeue operations, and how the call stack drives program execution. Pick the single best answer.

Q1. Five shoppers join a single checkout line in this order: Ana, Bo, Cy, Dee, Eli. The cashier serves them one at a time with no cutting. Who is the third person to leave the line?

  1. A Ana
  2. B Bo
  3. C Cy
  4. D Dee

Q2. You stack grocery cans in a tall pile, placing them in this order (bottom to top): Soup, Beans, Corn, Peas. You can only take the can on top. If you remove exactly two cans, which cans are left in the pile?

  1. A Soup and Beans
  2. B Corn and Peas
  3. C Soup and Peas
  4. D Beans and Corn

Q3. A stack starts empty. You perform: push A, push B, pop, push C, push D, pop. What is on top of the stack now?

  1. A A
  2. B B
  3. C C
  4. D D

Q4. You add the values 1, 2, 3, 4, 5 (in that order) to an empty queue, and the same values in the same order to an empty stack. You then remove everything from each. The first value out of the queue and the first value out of the stack are, respectively:

  1. A 1 and 5
  2. B 5 and 1
  3. C 1 and 1
  4. D 5 and 5

Q5. You visit web pages in this order, clicking links forward: Home → News → Article → Photo. Then you press the browser Back button twice. What page are you looking at?

  1. A Home
  2. B News
  3. C Article
  4. D Photo

Q6. A text editor implements Undo with a stack. You type the words the, then cat, then sat (three actions pushed in that order). You press Undo once, then type ran, then press Undo once more. Which word did that final Undo remove?

  1. A sat
  2. B cat
  3. C ran
  4. D the

Q7. A program runs this code:

function a() { b(); }
function b() { c(); }
function c() { /* pause here */ }
a();

Execution is paused inside c(). Reading the call stack from top to bottom, what is the order of frames?

  1. A a, b, c
  2. B c, b, a
  3. C main, a, b (c hasn't been pushed yet)
  4. D c, a, b

Q8. When the paused c() from Q7 finishes and every function returns normally, in what order do the frames get popped off the call stack?

  1. A a, then b, then c
  2. B c, then b, then a
  3. C b, then c, then a
  4. D They are all removed at the same time

Q9. A print server receives four jobs and must print them fairly in the order received: Report, Photo, Essay, Invoice. A coworker says “the printer works like a stack, so the last job sent prints first.” What is wrong with their claim, and what actually prints first?

  1. A Nothing is wrong; Invoice prints first
  2. B A fair print queue is FIFO, not a stack, so Report prints first
  3. C It is a stack, but stacks are FIFO, so Report prints first
  4. D A print queue is a stack, so Essay prints first

Q10. You need a data structure that lets you take a list of items and produce them in reverse order, using only its normal add/remove operations. Which choice works, and why?

  1. A A queue, because dequeue returns items in reverse of how they were enqueued
  2. B A stack, because popping returns items in the reverse of the order they were pushed
  3. C A queue, because it is FIFO
  4. D Neither can reverse a list without extra sorting
